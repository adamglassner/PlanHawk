# Changelog

## 0.1.1 (2026-11-25)

Polish for smaller screens.

- Gantt chart: the hint under the chart wraps instead of running off the edges; task details use shorter dates and a compact edit button.
- Dependencies: the diagram starts at the top left, scrolls to the selected task, and the color key floats over the diagram instead of crowding the toolbar.
- Home: shorter card titles and a two-line greeting.
- Tasks: the table drops the Project column (tasks are already grouped by project), so names have more room.

## 0.1.0 (2026-11-25)

First preview: the PlanHawk shell in Bytehawk's Hawkline style.

- Hawkline sidebar: New task, search, Home, Gantt chart, Tasks, Dependencies, Timeline, Board, Calendar, Resources, Reports, Templates, a project list, light/dark mode and Settings.
- Gantt chart: task sheet and timeline side by side with summary bars, milestones, progress, dependency arrows, a today line and the critical path. Collapse summaries, zoom (days, weeks, months) and see each task's predecessors and successors.
- Tasks: every task in every project, with project and status filters.
- Dependencies: a network diagram of each project with every link listed.
- Home: project cards, upcoming milestones, this week's work, tasks that are behind and a timeline of all projects.
- Three sample projects, scheduled from their dependencies. Editing, saving and opening Microsoft Project files are marked coming soon.
